# DNN Platform Language Pack for Turkish (tr-TR) — Archive

Turkish (Türkiye) core language packs for [DNN Platform](https://github.com/dnnsoftware/Dnn.Platform)
releases 08.00.00 to 10.03.03. Every DNN Platform release has one commit and one tag (`v{version}`).

This version: **DNN Platform 9.4.1** (`09.04.01`), released 2019-10-02.

The packs started from the community translations on
[dnncommunity.org](https://dnncommunity.org/Extensions-Ecosystem/Languages). Missing strings were translated,
so every resource file in the pack is fully Turkish, and the terminology follows the
[Turkish translation style guide](https://github.com/idumlupinar/Language-Pack-TR-TR/blob/develop/.github/COMMON_TERMS.md).

## Contents

Path | Purpose
--- | ---
`Resources/` | Contents of the install package, mirroring the DNN Platform site folder structure
`Resources/DNNCE_tr-TR.dnn` | Package manifest (`CoreLanguagePack`)

## Installation

Zip the contents of `Resources/` (the manifest must be at the root of the zip) and install it in DNN Platform
under **Host > Extensions** (8.x) or **Persona Bar > Settings > Extensions > Install Extension** (9.x and later).
Use the tag that matches your DNN Platform version.

For DNN Platform 10.04.00 and later, see [Language-Pack-TR-TR](https://github.com/idumlupinar/Language-Pack-TR-TR).
